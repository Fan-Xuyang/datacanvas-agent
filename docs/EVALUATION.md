# DataCanvas 经营报表分析 Agent评测记录

当前未配置模型接口。本次仅测固定合成用例上的离线规则规划与实际工程流程，不是大模型准确率，不是独立留出集上的泛化效果，也不是生产系统效果。

## 可复核结果

查询数值与独立 Python 汇总结果一致：100/100。

越界/缺失信息用例拒绝：6/6。
本地完整流程完成：10/10；工程检查通过：40/40。
工程流程 p50 1.06 秒，p95 1.25 秒。当前样本量很小，浏览器流程由测试立即确认；耗时包含被选中的服务重启，不代表真实用户等待时间、并发吞吐或模型推理速度。

## 口径与样本

80 条来自 4 个指标（销售额、成本、订单量、毛利）×4 个分组方式×5 个聚合运算；20 条来自记录数×4 个分组方式×5 种筛选配置。期望值由 csv、defaultdict 和 statistics 独立计算，实际 SQL 经真实 DuckDB 子进程执行。

10 条 HTTP 任务验证创建、真实 SQL 数值、完成状态、报告下载和 SSE 游标重放，共 40 项断言。

原演示规划器仅按销售额与区域等少量模式生成 SQL，在这套扩展功能用例上为 4/100；新规则规划器为 100/100。

这套用例与实现一起维护，用于发现功能回归；不能将上述提升称为在相同能力范围的独立测试集上提升模型准确率。当前未覆盖复杂多条件表达、任意字段语义、任意网页和分布外任务。6 条负例也不代表完整攻击面覆盖。
