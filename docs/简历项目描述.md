# DataCanvas 简历项目描述

**DataCanvas 材料行业经营数据分析 Agent｜个人独立项目，获业务方采纳**

技术栈：Python／FastAPI／DuckDB／SQLGlot／Pydantic／React／TypeScript／ECharts／SQLite／SSE。

- 面向材料行业经营数据分析，独立搭建 CSV／Excel 导入、自然语言查询、图表及报告应用；业务人员可核对明细、实际 SQL 和数据来源。
- 将表结构和指标说明传入规划器，输出 SQL／ChartSpec；使用 Pydantic 校验结构、SQLGlot AST 限制表和函数范围，并通过只读进程、超时和资源限制执行；遇到 SQL 或字段错误最多反馈修复两轮。
- 保存任务计划、执行结果和事件，支持 SSE 断线重放及中断恢复。100 条固定合成规则用例与独立 Python 汇总一致，10 条本地接口流程通过；以上验证规则与工程链路，未调用真实模型。

公开仓库是可复现演示版本，合成数据不包含企业业务数据。实际业务采纳事实与仓库中的模型效果评测口径分开说明。
